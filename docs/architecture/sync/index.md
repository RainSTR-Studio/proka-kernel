# 同步原语与并发控制

在多核 (SMP) 环境下，确保内核数据结构的一致性至关重要。

## 底层原语

- **原子操作 (Atomics)**：利用 Rust 标准库提供的原子类型处理简单的计数与标志。
- **自旋锁 (Spinlocks)**：最基础的互斥机制，在等待时不挂起 CPU。
- **中断屏蔽**：在单核临界区通过 `cli`/`sti` 保证操作的原子性。

## 设计原则

- **死锁避免**：严格的锁顺序约定。
- **最小化持有时间**：仅在必要的内存读写期间持有锁。
